# Reviewly

A local-first study reviewer for the AP6 Cross-Platform lesson files in `lessons/`.

## Run it

Open `index.html` in a browser, or serve the folder with any static file server. No build step or backend is required.

## Included in this first version

- Dashboard with lesson progress and quiz accuracy
- Lesson library and source-linked lesson reader
- Key points and key terms for each available PDF
- Flashcards with flip and next/previous controls
- Practice quiz with immediate feedback
- Progress saved in browser local storage
- Responsive mobile layout

The current content is a starter structured dataset. The next useful step is to validate each summary and question against the actual instructor material, then add the exam structure and question types for the subject.
